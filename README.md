# DailyFlow - 智能任务管家

> 🎯 一款简洁高效的个人任务管理工具，帮助你追踪每日任务，智能处理未完成事项。

## ✨ 功能特点

### 📋 任务管理
- ✅ 快速添加任务，支持优先级和重要程度设置
- ✅ 拖拽排序，灵活调整任务顺序
- ✅ 点击任务查看详情，记录任务概要
- ✅ 完成任务、编辑、删除等完整操作

### 📝 子任务清单
- ✅ 为每个任务添加多个子任务
- ✅ 子任务支持拖拽排序
- ✅ 子任务点击即可编辑
- ✅ 实时显示完成进度

### 🔔 智能提醒
- ✅ 第二天自动弹出未完成任务
- ✅ 可选择：保留到今天 / 标记完成 / 遗弃
- ✅ 支持批量操作

### 💾 数据安全
- ✅ 本地存储，数据永不丢失
- ✅ 支持导出/导入 JSON 备份
- ✅ 自动保存，无需手动操作

## 🚀 快速开始

### 在线访问
直接打开 `index.html` 文件即可使用，无需任何安装。

### 本地运行
```bash
# 克隆项目
git clone https://github.com/YOUR_USERNAME/dailyflow.git

# 进入目录
cd dailyflow

# 使用 Python 启动本地服务器（可选）
python -m http.server 8000

# 浏览器访问 http://localhost:8000
```

## 🛠️ 技术栈

- **前端**: 原生 JavaScript (Vanilla JS)
- **样式**: CSS3 (CSS Variables)
- **拖拽**: SortableJS
- **图标**: Font Awesome 6
- **存储**: LocalStorage

## 📖 使用指南

### 创建任务
1. 在顶部输入框输入任务标题
2. 按 Enter 或点击"添加"按钮
3. 可选：展开"高级选项"设置优先级和重要程度

### 任务详情
- 点击任务内容区域打开详情弹窗
- 在"任务概要"中记录详细信息
- 在"子任务清单"中添加子任务

### 子任务操作
- 📌 拖拽左侧手柄调整顺序
- ✏️ 点击文本直接编辑
- ✅ 点击复选框标记完成
- 🗑️ 点击 × 删除

### 处理未完成任务
- 每天首次打开应用会显示昨日未完成任务
- 可单独处理或批量操作
